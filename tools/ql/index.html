上: 直近の生のスペクトル（10.24 ms のダンプの平均。観測が終わった後は、その観測の最後の値）。下: Ta* = Tsys × (ON − OFF) / OFF（Tsys が決まる前は比のまま）。「随時」は観測中に 1 秒ごと、生のスペクトルを ON とみなして直近の OFF と比べる（OTF の ON の途中から見える。ON の間だけ意味があり、R・OFF の間の値は無意味）。「積分ごと」は直近の ON の積分と、その前の OFF（観測が終わった後は、どちらを選んでもこれ）。 グラフの上にマウスを置くと値を出す。 Vlsr = Vsrc + c·(1 − f / frest)（電波の定義。Vsrc は L1 の dstrv。ロギングの周波数はドップラー追尾した系）。frest の既定は L1 の dcent_freq（丸めてあることがあるので、線の静止周波数を窓ごとに入れられる）。
