# SAM45 のロギングの形式

SAM45 LC が書くロギングのファイルの形式。YATSUGATAKE が設定を読み、スペクトルを差し込む先になる。

> 出典: COSMOS の `sam_log.h`・`sam_common.h`（ヘッダのバージョン V004.1）と、
> 実際のロギング 1 観測分（2026-09-10、PSW、A05・A06・A13・A14。A05・A06 は故障前）を突き合わせて読んだ（2026-11-06）。
> `.h` とサンプルはリポジトリに入れていない（扱いを確認中）。ここには形式の要約だけを書く。
> 説明のうち「（聞き取り）」は西村さんからの聞き取り（2026-11-06）。

## ファイル

- **1 観測 1 ファイル**。全 Array の分が 1 つのファイルに入る
- ファイル名: `<ログ ID>.SAM45.<指示書名>.<group>.<project>`（例 `20260910183522.SAM45.rcash40.csv26.squint`）。
  L0 の中の名前は `SAM45.<指示書名>.<group>.<project>.<ログ ID>`
- **バイナリ、little-endian**。構造体は 8 B 境界の自然な並べ方（構造体の大きさと実ファイルのレコード長が一致した）
- `.h` のコメントは EUC-JP
- **ファイルができ、L0・L1 が書かれるのはログ ID の時刻**（聞き取り）。その後、積分ごとに L2 が足され、最後に ED が書かれる

## レコード

どのレコードも頭に 8 B（種類 `char[4]` ＋ 長さ `int`）を持つ。**長さは頭の 8 B を除いた値。**

| 種類 | 構造体 | 大きさ（頭を含む） | 数 | 中身 |
|---|---|---|---|---|
| `L0` | LOG_CTL | 88 B | 1 | ヘッダのバージョン・ロギングの名前・バックエンドの種類（`SAM45`） |
| `L1` | LOG_OBS | 8472 B | 1 | 観測の情報（**分光の設定を含む**） |
| `L2` | LOG_DAT | 17064 B | 積分ごと × Array ごと | 付加情報 ＋ スペクトル（float32 × 4096） |
| `ED` | LOG_END | 8 B | 1 | **終わりの印** |

サンプル: L0 1・L1 1・L2 208・ED 1 で、合計がファイルの大きさ（3,557,880 B）にちょうど一致した。

## L1（観測の情報）のうち、肩代わりで使う欄

Array ごとの欄は 32 要素の配列（添字 0 = A01 … 31 = A32）。

| 欄 | 中身 | サンプルの A05 |
|---|---|---|
| `iary_usefg` | 使うか（0 / 1） | 1 |
| `ichannel` | ch 数 | 4096 |
| `dbebw` | 帯域 [Hz]（2000e6・1000e6・500e6・250e6・125e6・62.5e6・31.25e6・15.625e6） | 31.25e6 |
| `dbechwid`・`dberes` | ch の間隔・分解能 [Hz] | 7629.39 |
| `dflif` | 受信機の出力の 1st IF [Hz]（この後にも IF 系が続く。聞き取り） | 6e9 |
| `dcent_freq`・`dtrk_freq`・`dfqdat_f0` | 中心の周波数 [Hz] | 43.122e9 |
| `dfqdat_fq[2]`・`dfqdat_ch[2]` | 周波数と ch の対応の 2 点 | 43106.38 MHz ↔ ch 4096、43137.62 MHz ↔ ch 1（**ch が増えると周波数が下がる**） |
| `csid_type` | サイドバンド（USB・LSB・DSB） | USB |
| `iary_ifatt` | R のときに足す IFATT [dB]（−9〜9。Tsys と強度の計算で使う） | 5 |
| `iary_refno` | リファレンスのシンセサイザの番号 | 11 |

SAM45 に固有の欄（サブアレイ × SpW）: `in_spec_window`（窓の数）・`istart_chan`・`iend_chan`・`ichan_avg`（524,288 ch のうち使う範囲と束ねる数。サンプルでは 258048〜266239 を 2 個ずつ束ねて 4096 ch）・`cinput_mode`・`cwin_func_id` など。

観測全体の欄: `clog_id`（ログ ID）・`cst_time`（観測の開始 JST）・`cobs_file`（指示書名）・`isw_mod`（1 POS・5/6 FREQ）・`iotf_mode`・`diptim`（OTF のデータの間隔 [s]）・`cseq_ptn` など。

## L2（積分ごと・Array ごと）のうち、肩代わりで使う欄

| 欄 | 中身 | サンプル |
|---|---|---|
| `cary_name` | Array の名前 | `A5`（ゼロ詰めしない） |
| `iary_no` | 40 ＋ Array の番号 | 45 |
| `cscan_type` | ZERO・R・SKY・ON・OFF など | |
| `cscanid` | スキャン ID | `260910183522.00002` |
| `cint_sttm`・`cint_edtm` | 積分の開始・終了（JST、`YYYYMMDDHHMMSS`。**PSW は 1 s の分解能**、OTF の `cint_sttm` は積分の中心で ms まで） | 18:43:30・18:43:35 |
| `dint_stmjd`・`dint_edmjd` | 積分の開始・終了。**名前は MJD だが中身は MJD の起点からの秒** | 5295750210（= 2026-09-10 09:43:30 UTC） |
| `iinteg_time` | 積分時間 [s]（整数） | ZERO 1、ほか 5 |
| `dtsys` | Tsys [K]。SAM45 LC が計算する。QL・マージが参考値として表示する（聞き取り） | SKY 以降で 359.2 など |
| `idmy_flag` | データの無効の印（0 有効・1 無効） | 0 |
| `dweather[5]` | 気温・気圧・水蒸気圧・風速・風向 | 14.3 °C など |
| `fary_data[4096]` | スペクトル（float32） | |

`L2` には SAM45 では使っていない GPU の欄（`dcenter_frequency` 2〜4 GHz、`istart_channel`・`inumber_channels`、窓関数など）がある（サンプルでは全部 0）。

## サンプルで見た並びと値

- 積分ごとに、使う Array の L2 が A5・A6・A13・A14 の順に 1 つずつ並ぶ
- スキャンの並び: ZERO（1 s）→ R → SKY → ON / OFF の繰り返し（各 5 s）
- 値: ZERO は全 ch が 8192 で一定。R ≒ 4.6e4、SKY ≒ 7.4e4（R は IFATT 5 dB を入れた後なので SKY より小さい）
- 時刻: ログ ID 18:35:22、`cst_time` 18:43:00、ZERO 18:43:26、R 18:43:30
