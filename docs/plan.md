# 作業の一覧

sam45compat の残りの作業。方式と決めたことは [`design/standin-study.md`](design/standin-study.md) にある。
終わった項目は `[x]` にし、日付を書く。調査でわかった既存のシステムの事実は [`cosmos/observation-flow.md`](cosmos/observation-flow.md) に書く。

> 2026-11-06 時点。設定とタイミングは SAM45 のロギングの監視だけで得る（MLPPS は使わない）。
> ロギングの形式はわかった（[`cosmos/sam45-logging.md`](cosmos/sam45-logging.md)）。周波数軸は f2（L1 の書き換え）。
> 進め方は段階 1 → 1.1 → 1.5 → 2（[`design/standin-study.md`](design/standin-study.md) の「段階の進め方」）。YKSP のロギングを SAM45 の形式で別に書き、既存のマージにかける。
> 2-1（specd の制御と記録）・2-2（ロギングの監視）・2-3（YKSP のロギングの書き出し）は始められる。

## 2. 段階 1（別のロギング・同じ IF・IFATT に従う・手でマージ）

- [x] **2-0. 土台**: YATSUGATAKE v1.4.0 を submodule で固定、`pyproject.toml`、`samlog.py`（ロギングの読み書き・追いかけ読み。サンプルをバイト単位で読み書きできることを試験で確認）（2026-11-06）

- [ ] **2-1. specd の制御と記録**（`mapping.py`・`board.py`・`recorder.py` で済み。YATSUGATAKE の `specd.py --fake` を相手に、準備・記録・束ね・暫定 LC を通した。残りは実機で: 本物の時刻・LOAD・Wide。2026-11-06）: SAM45 の設定（L1 から読んだもの）を YATSUGATAKE の bit と SET に変換し（Wide と Fine が混ざるときは 250 MHz 以下だけ）、LOAD（bit が変わるときだけ）・SET・START する。10.24 ms のスペクトルを時刻付きで一時ファイルに記録する
- [ ] **2-2. ロギングの監視**（`lc.py` で済み。模擬の分光計と `tools/replay.py` でサンプルを通した。残りは実機の分光計 2-1 とつなぐこと。2026-11-06）: 新しいファイルを見つけ（1 s 程度の見回り）、L1 から設定を読み、2-1 に渡す。最初の R までに記録を始める。ED で観測の終わりを判定して記録を止める。異常は自分のログに残し、運用者に知らせる
- [ ] **2-3. YKSP のロギングの書き出し**（`binning.py`・`yksp.py`・`lc.py` で済み。2026-11-06）: `.YKSP.` の名前で、SAM45 と同じ形式のファイルを書く。L0 は写す（中は `SAM45` のまま）。L1 は写して、肩代わりする Array だけの設定（`iary_usefg`・`iary_num`）・周波数の欄（f2）・`iary_ifatt`（IFATT のモード）を書き換える。L2 は SAM45 の L2 に合わせて、区間の 10.24 ms のダンプを束ねて書く（ZERO は 8192、できれば `dtsys` も）。ED を書いたら一時ファイルを削除する。2-1〜2-3 で暫定 LC になる
- [ ] **2-4. 同じ IF の観測**: A01〜A04 と同じ IF を A05〜A08（RFSoC）に入れ、A01〜A08 を同じ周波数・帯域にした指示書で観測する
- [ ] **2-5. 手でマージ**: SAM45 と YKSP（ファイル名を SAM45 に擬態）を別々にマージする。YKSP だけの L1 でマージが通るかを見る（通らなければそのとき考える）
- [ ] **2-6. 比べる**（道具は `compare.py`: `python3 -m sam45compat.compare <SAM45> <YKSP> [--npz] [--png]`。SAM45 の A05 を YKSP の軸に補間した模擬で、軸・較正が一致することを確認。2026-11-06）: SAM45（A01〜A04）と YKSP（A05〜A08）の生の値（ZERO・R・SKY・ON・OFF）・周波数軸・時刻・Tsys・スペクトル線を比べる。準備の時間（最初の R に間に合うか）と異常の通知も確かめる

## 3. 段階 1.1（観測後に合体・手でマージ）

- [ ] **3-1. 合体の処理**（`combine.py`。`python3 -m sam45compat.combine <SAM45> <YKSP> -o <出力>`。サンプルで確認。2026-11-06）: SAM45 のロギングと YKSP のロギングから、1 つのファイルを作る（SAM45 の L1 の肩代わりする Array の欄を書き換え、肩代わりする Array の L2 を YKSP のもので差し替える・足す）。段階 2 でそのまま使えるように作る
- [ ] **3-2. 手でマージして比べる**: 段階 1 のデータで合体し、マージが通るか、1 つの観測生データの中で A01〜A04 と A05〜A08 を比べる

## 4. 段階 1.5（IFATT を無視する）

- [ ] **4-1. IFATT の制御プログラムの改修**: IF 入力 5〜8（A05〜A08・A21〜A24）では R のときの ATT の追加を無視する（SKY のレベル合わせはそのまま）。肩代わりをやめるときに戻せるようにする
- [ ] **4-2. 暫定 LC を「無視する」モードに**: L1 の `iary_ifatt` を 0 に書き換える
- [ ] **4-3. 同じ IF で観測・合体・手でマージ**: 較正後の値（Tsys・強度）が SAM45（A01〜A04）と合うかを確かめる。SKY でレベルを合わせたときの RFSoC の入力のレベルも見る

## 5. 段階 2（本番: 観測中に合体）

- [ ] **5-1. SAM45 LC の改修**（別の担当者）: ロギングを `_` を頭に付けたファイル名で書く。設定で元に戻せる形にする
- [ ] **5-2. 観測中の合体**（`lc.py` の `output: combined`。L0・L1 は準備を待たずに先に書く。模擬で確認。2026-11-06）: 暫定 LC が `_` のファイルを追いかけ、3-1 の処理で合体して、正規の名前のファイルに積分ごとに書く。SAM45 の ED から ≒ 1 s 以内に ED を書く
- [ ] **5-3. 止まったときの備え**（`lc.py` の心拍・受け持ちの印、`watchdog.py`。途中で落ちた場合を模擬で確認。2026-11-06）: (1) YATSUGATAKE の異常では SAM45 の分を素通しで写し、肩代わりの分は `idmy_flag` = 1 で運用者に知らせる。(2) 暫定 LC が落ちたときに `_` のファイルを正規の名前に写すだけの見張りを別に置く。両者の受け持ちの切り替え（同時に書かない）を決めて試験する
- [ ] **5-4. 本番の IF に戻す**: IF 入力 5〜8 を本来の IF に戻す
- [ ] **5-5. 本番の観測での確認**: QL に出るか、マージが通るか、観測者の手順が変わっていないか
